# World art pipeline

The art pipeline keeps OpenCoaster independent of original game files and copied code. The committed source sheets under [source/](source/) are newly generated artwork; their generation prompts are kept in [prompts/](prompts/). Normal development and production builds consume these saved sheets and do not call an image-generation service.

## Preparation

[prepare.ts](prepare.ts) clears and recreates `public/sprites/`, then crops, trims transparent padding, defringes transparent-edge RGB, resizes with nearest-neighbour sampling, and quantizes images to a deterministic 64-colour palette. Per-sprite JSON records frame rectangles, bottom-centre anchors, and tile footprints. [pack.ts](pack.ts) validates that metadata, sorts world sprite frames by dimensions and stable key, packs them into a transparent PNG atlas, and writes the frame locations and metadata to `manifest.json`. The generated atlas is capped at 1024 pixels wide by 2048 pixels high; packing fails if a source sprite or packed result exceeds those limits. The standalone UI icon sheet is written to `public/sprites/ui/` and excluded from the world atlas; the DOM loads it directly. The atlas width cap leaves room for the procedural fallback atlas when WebGL combines both textures, keeping each combined dimension within WebGL2's 2048-pixel minimum texture-size guarantee.

The terrain sheet supplies distinct source cells for the 16 combinations of the map's 4-bit corner slope mask, plus directional cliff faces, for each of grass, sand, dirt, and rock. Preparation crops and cleans each authored cell; it does not rotate or reflection-cycle a smaller set of slope drawings. These slope and cliff cells are catalogued but are not selected by the current terrain renderer, which samples an opaque per-material surface texture derived from the material's flat terrain art while projecting tile corners to their map heights. The map encodes one-level corner differences and has no steep-slope encoding, so steeper cliffs are unsupported.

Path sprites use 96-pixel tiles. Tarmac connections are cropped from the source sheet; crazy-paving, dirt, and queue styles are deterministic palette/texture variants, and directional ramps are formed from connection sprites by pixel displacement. The water sheet supplies the four frames of one animation. The props sheet supplies ambient trees, placeable scenery, queue rails, and other park props; the saved prompt and source image remain the reproducible inputs. Source sheets are newly generated artwork and must not be replaced with original game sprites.

Run `pnpm art:prepare` to regenerate the individual PNG/JSON pairs, then `pnpm art:pack` to build the atlas and manifest. The `predev` and `prebuild` hooks run both steps automatically. `public/sprites/` is generated output; make source-sheet or prompt changes in `source/` and `prompts/`, then regenerate the output.
