# Decisions

Resolutions of the cross-spec conflicts listed in `docs/mechanics/README.md`. Constants marked _tunable_ live in code as named constants and are calibrated in playtesting.

| Topic                         | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tick rate                     | 40 ticks/s (`TICK_RATE`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| World model                   | Tile element stacks per tile (engine spec). Track uses the same tile grid; sub-tile geometry belongs to track pieces, not the map.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Calendar                      | 16,384 ticks per month, 8 months per year (March-October). Tunable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Wages                         | Accrue weekly; reported monthly in the finance report.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Excitement penalty            | ×0.75 per intensity threshold exceeded. Tunable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Park rating                   | Integer, clamped 0-999. Formula per economy spec including the ride terms; calibrated in [BALANCE.md](BALANCE.md).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Food/drink seeking            | A hungry/thirsty guest heads to a known stall if it has seen one; otherwise wanders and buys on encounter.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Capacities                    | 8,192 guest slots; ride and entity ids are 32-bit. The 5,000-guest mixed-staff-and-litter benchmark must stay at or under 3 ms/tick at p99.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Park rating happiness         | Penalty `500 - 2 x min(250, 3 x happy%)` per the rating-formula guide; a guest is happy above 50% happiness. Uses whole-percent inputs, so an empty park takes no penalty (the guide leaves the zero-guest case open). _Tunable._                                                                                                                                                                                                                                                                                                                                                                                                        |
| Difficult rating              | Scenario flag `difficultRating` (default off) starts the rating from 1,050 instead of 1,150. Stored in the ledger, hashed, saved (additive, default off).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Rating terms not yet modelled | Casualties use 100 per casualty (guide: 25 per drowning, 200 per fatal crash, with decay) until per-type inputs exist. Park value keeps the ride-value-plus-$7-per-guest placeholder until rides expose five-minute rider counts and type bonuses; the duplicate-type 25% reduction waits for the same work.                                                                                                                                                                                                                                                                                                                             |
| Loans and interest            | Keep simple weekly interest: annual basis points x balance / 32 weeks, floored, charged on the weekly boundary. Repayment is immediate and limited by cash. The guide does not settle simple vs compound, the sampled balance, or rounding; these wait for a controlled RCT2 observation. Loan steps are $1,000.                                                                                                                                                                                                                                                                                                                         |
| Company value                 | Park value + cash - loan (strategy guide). Already implemented; no change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Marketing                     | Six campaign families, ids 0-5 in manual order (ids 0 and 1 unchanged). Durations 1-6 weeks, one running campaign, replacement on start. Weekly prices and attraction multipliers are unsourced hypotheses (the manual transcriptions disagree): free park-entry $50, park advertising $150 (unchanged), free ride vouchers $75 and selected-ride advertising $80 (ride target), half-price entry $60, free food or drink $40 (item target). The ride or item target is stored; targeted campaigns still give the park-wide bonus until the guests workstream applies per-target effects. Voucher fulfilment is not modelled. _Tunable._ |
| Research funding              | Funding is charged monthly, $0 / $100 / $200 / $400, on the month boundary (before the rollover). Progress accrues weekly: 21 / 28 / 42 work units at minimum / normal / maximum, that is 3 / 4 / 6 units a day over seven days. An invention of 180 units takes 60 days at minimum, 45 at normal and 30 at maximum, as the reference reports. Costs are scenario-set in work units. _Tunable._                                                                                                                                                                                                                                          |
| Research order                | Empty category mask pauses progress while funding is still charged (the manual's reading). The community fallback to remaining categories is not adopted. Player priority is an ordered item list; unranked items follow scenario order; unknown or repeated ids are rejected.                                                                                                                                                                                                                                                                                                                                                           |
| Calendar and month length     | Sim weeks are treated as seven days, four weeks to a month, so 60/45/30-day intervals map to 8.6/6.4/4.3 weeks. The mechanics note's 32-day month conflicts with this and is open. Display day labels stay 30/31 days. Same-tick order: research, then the economy's weekly charges, then fortnightly upkeep, monthly rollover and the rating refresh.                                                                                                                                                                                                                                                                                   |
| Scenario objectives           | Judged once, on the first tick at or after the deadline (kept). Monthly income reads the last completed month. Other goal timings wait for scenario-by-scenario RCT2 checks.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Awards                        | Deferred: no award catalogue, lifecycle or effect exists yet. The guide's four-month duration and 1.25 / 0.75 multipliers are unverified.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Starter rating target         | 550. On the current default seed (2026), the scripted modest build ends at rating 570 and wins with 20 points of margin. Seeds 11–16 and 21–26 range from 484–690 and win 10 / 12 at this target. See [BALANCE.md](BALANCE.md#guest-fidelity-on-the-combined-baseline).                                                                                                                                                                                                                                                                                                                                                                  |
| Save format                   | Version 12. Version 10 added guest navigation and research work units; version 11 added ride reliability, mode and mechanic-work columns; version 12 adds guest visit and ride-history columns. Saves through v11 invert hunger/thirst into satiation and map old nausea tolerance to four buckets. Version 10 and 11 navigation/research data and version 11 ride data remain intact. Versions 9 and older store research costs and progress in cents, which convert at the old minimum rate (2,500 cents a week = 21 units). Additive economy/research fields default when absent.                                                     |
| Guest cadence                 | Need decay every 128 world ticks; happiness motives every 512 ticks, matching the audited original cadence summary.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Hunger and thirst             | Values count satiation: high means full; low means hungry or thirsty. Loading saves through v11 inverts both bytes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Legacy nausea tolerance       | Map old bytes 96–255 into equal 20-value bands, then map 0 / 1–2 / 3–5 / 6–7 to none / low / average / high. This preserves the audited category distribution; the exact preference mapping is an implementation choice.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Guest leaving and queue balk  | A guest with no ride destination may leave after 10,240 ticks when energy <55, happiness <45 or cash <$5, with a 5% check every 512 ticks. An unhappy thrill-queue guest may balk after 4,300 ticks with a 3.3% check every 128 ticks. These thresholds follow the guest fidelity audit and are tunable.                                                                                                                                                                                                                                                                                                                                 |
| Repeat rides                  | Remember the last ride and ride count. Repeating that ride requires the audited rating, intensity and guest-need checks, then a random roll.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Rain happiness                | No direct happiness loss: the guest audit found no supporting source. Keep the separate rain ride-choice penalty and kiosk umbrella behavior.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Vandalism                     | Eligible wandering guests need happiness <48, energy ≥85 and existing park litter; each eligible check has a 5% chance. Disgust is not modeled, so the local gate is a documented approximation.                                                                                                                                                                                                                                                                                                                                                                                                                                         |

## Rides: values chosen where the fidelity docs mark a number open

Source: [fidelity/rides.md](fidelity/rides.md). All of these are named constants in `src/sim/rides`.

| Topic                  | Decision                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Target catalogue       | Base RCT2 without the Triple Thrill Pack. The catalogue itself is not yet built.                                                                                                                                                                                                                                                                                                                                             |
| Inspection clock       | One original-game minute is 2,400 ticks (a minute at 40 ticks/s, as the old one-hour default). Choices: 10, 20, 30, 45, 60, 120 minutes or never; new rides use 30 minutes (`INSPECTION_INTERVAL_MINUTES`). Stalls and facilities are never inspected.                                                                                                                                                                       |
| Reliability            | 0-25,855 scale (256 per percent), checked when the global tick is a multiple of 256, roll `rng.int(3,145,728) < 25,857 - reliability`, forced at zero (all from the doc). Rides start at 25,855. Wear and breakdown rolls pause while a ride is broken.                                                                                                                                                                      |
| Wear per check         | `unreliability` per type: merry-go-round 4, Ferris wheel 4, swinging ship 7, twist 8, wooden coaster 10, steel coaster 14 (units of 1/256 percent), times an age percentage by ride year: 100, 100, 125, 150, 200, 250, 300, 400 (`AGE_WEAR_PERCENT_BY_YEAR`). Unsourced. A ride loses 8-28% of its reliability in its first year, so in the scripted park most rides finish year one at 86-93% and at most one breaks down. |
| Breakdown reasons      | Flat rides: safety cut-out 20, restraints stuck closed 12 and open 10, control failure 6 (Ferris wheel: doors stuck closed 10 and open 8, control failure 4). Coasters use the documented mine-train mix 25/12/10/6/3 with brakes failure 20 in wet weather. The wet weight applies to rain and storm. Stalls never break down.                                                                                              |
| Repair                 | Mechanics must stay at the ride: 200 ticks for a safety cut-out, 360-400 for restraint and door failures, 480 for control failure, 600 for vehicle and brakes failures (`REPAIR_TICKS`); 240 ticks for a routine inspection. A repair does not restore reliability; only an inspection does. Restraints or doors stuck closed keep riders aboard until repair.                                                               |
| Inspection restore     | `floor((100 - whole percent) / 4) x random byte (0-255)` units, as in the doc, capped at 25,855.                                                                                                                                                                                                                                                                                                                             |
| Ride value             | `sum(floor(rating x weight x 32 / 32768))`, one unit is ten cents. Weights (E/I/N): merry-go-round and Ferris wheel 60/16/10, swinging ship 50/32/10, twist 50/32/10, coasters 51/32/10 (the doc's worked example).                                                                                                                                                                                                          |
| Novelty bonus          | The two fidelity-doc sources disagree: [fidelity/rides.md](fidelity/rides.md) gives +30 and +10 internal points, [mechanics/rides.md](mechanics/rides.md) gives +$6 and +$2. We follow the former (+30 under five months, +10 up to twelve), with age bands as in the fidelity doc.                                                                                                                                          |
| Same-type penalty      | Once two rides of a type are open, every ride of that type is cut to 75%, applied after the age adjustment. A third ride does not cut further.                                                                                                                                                                                                                                                                               |
| Price reaction         | Good value at price <= value / 2, too expensive at price > 2 x value. The 75% admission-paid willingness cut is not applied.                                                                                                                                                                                                                                                                                                 |
| Load targets           | 1/4, 1/2, 3/4, full map to thresholds 63, 127, 191, 255 (`floor(fraction x 255)`) so a ride dispatches at exactly that share of capacity. New rides default to 1/2.                                                                                                                                                                                                                                                          |
| Ferris wheel direction | Backward adds 0.10 excitement. The doc says the modes differ but gives no value or sign.                                                                                                                                                                                                                                                                                                                                     |
| Stall prices           | Food $1.20, drink $0.80, information kiosk $1.00, toilets $0.20. Unsourced; item costs and weather demand are left to the guest module.                                                                                                                                                                                                                                                                                      |
| Mechanic target        | A track ride has no tile, so mechanics walk to a tile next to its exit.                                                                                                                                                                                                                                                                                                                                                      |
| Save format            | Version 11 appends five reliability, mode and mechanic-work columns to the ride store. Saves through version 10 scale stored percent reliability and use each ride type's default mode; version 10 guest-navigation data and research work units are preserved.                                                                                                                                                              |

## Coaster fidelity (docs/fidelity/track.md)

| Topic                     | Decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Speed scale (G-15)        | 1 world unit per tick = 5.1 km/h, the scale at which the force model reproduces the 2.8 G speed table. Constants live in `vehicles/speed-units.ts`.                                                                                                                                                                                                                                                                                                                                                                   |
| Crash limits (G-01..03)   | Crest 50 km/h, drop start 64 km/h, train collision 48 km/h combined (about 9.8, 12.6 and 9.4 units per tick). Crash checks are on by default. Crest and drop crashes apply only to ride types with `unattachedCars` (wooden coaster); the steel looping coaster has attached cars, so only collisions apply.                                                                                                                                                                                                          |
| Drop term unit (G-09)     | The 25x gap between the two sources is a unit mix-up: one lists ratings in points, the other in hundredths, and its "doubled height" accounts for the remaining factor of two. Both give 0.49 excitement, 0.98 intensity and 0.16 nausea (hundredths) per height unit. Height unit = half a track level (32 world units), matching the 2-unit track step in the track spec. Coefficients unchanged. Still unverified against the original; change `DROP_UNITS_PER_STEP` if playtest shows drops under- or over-rated. |
| Lateral G over 3.1 (G-14) | Excitement is halved (two sources agree; the third calls it a non-original mode).                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Base ratings (G-05)       | Track rides add their base values first, then bonuses and requirement divisions, then the intensity penalty, then multiply by the ride type's percentages. Multipliers (wooden 100/100/100, steel 110/105/100) are unsourced and tunable.                                                                                                                                                                                                                                                                             |
| Requirements (G-06)       | Each unmet requirement divides all three ratings by 2. Thresholds are unsourced and tunable per ride type (wooden: length 1024 units, drop 128 units, speed 30 km/h, 1 drop; steel: 1536, 192, 40 km/h, 1 drop). Station-count, reverser, hole and splashdown requirements do not apply (no such elements).                                                                                                                                                                                                           |
| Air time (G-10)           | One unit is one tick. Excitement +units/8 and nausea +units/16 with units capped at 200; limited-air-time profiles lose (units - 96)/8 excitement instead. No shipped type is limited.                                                                                                                                                                                                                                                                                                                                |
| Sheltered length unit     | One step is a quarter tile (64 world units) of track below the terrain surface. Tunable; the source gives no unit.                                                                                                                                                                                                                                                                                                                                                                                                    |
| Scenery and proximity     | Scenery within five tiles of the station, 0.05 excitement each up to 47; an underground station scores a fixed 0.40 instead. Other proximity terms (water, own track, paths) are not implemented.                                                                                                                                                                                                                                                                                                                     |
| Rating clamp (G-13)       | 0-32767.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |

## Parallel work conventions

- Each workstream owns its module directory under `src/sim/<module>` (or `src/render`, `src/ui`). Edits to `src/sim/core` (World, Command union, constants, `SYSTEM_ORDER`) must be small and additive; rebase on `main` before opening a PR.
- Every PR keeps `pnpm lint`, `format:check`, `typecheck`, `test`, `build` and `bench --guests 5000` green, and adds determinism tests (same seed, same `hashWorld`).
- Sessions cannot push `.github/workflows/`; ask the coordinator for CI changes.
