# RCT2 mechanics gap audit

Scope: compare the current OpenCoaster simulation with RollerCoaster Tycoon 2 (RCT2) behavior, using the RCT2 manual for player-facing rules and OpenRCT2 source/docs as a public implementation reference. OpenRCT2 is not proof of exact vanilla parity: it has its own changes and bug fixes. This is a clean-room audit; it records behavior and source paths only, and copies no implementation or assets. Impact is the likely effect on play; size is a rough implementation/calibration estimate (S/M/L/XL).

## Source and confidence notes

- The RCT2 manual is the primary source here for the player-facing finance, research, marketing, staff, weather, ride, and scenario interfaces. Its descriptions do not expose every formula.
- OpenRCT2 source is used as a navigable implementation reference for mechanics, not copied into this project. Its current implementation may differ from RCT2; validate compatibility-sensitive constants in the original game or mark them as deliberate OpenCoaster balance choices.
- Existing research specifications in [docs/mechanics](README.md) are useful leads, but some values are explicitly single-source, inferred, or unresolved. In particular, loan interest, wage cadence, park-rating base/formula, ride-rating thresholds, campaign prices, guest thresholds, award duration, and crash rules should not be promoted to “verified RCT2” without a controlled comparison.
- OpenCoaster's tests establish its own current behavior. They do not establish parity with RCT2. This audit did not run the game or tests; it read implementation, tests, and existing mechanics research.
